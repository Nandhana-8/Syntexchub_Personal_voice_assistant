# 🎙️ AI Personal Voice Assistant
A simple Python-based voice assistant that listens to voice commands and performs tasks like opening websites, telling the time/date, and searching on Google.

Built as part of the Syntexhub Internship Task 🚀

---

## ✨ Features
- 🎤 Voice Recognition
- 🔊 Text-to-Speech Response
- 🌐 Open Google, YouTube, GitHub, etc.
- ⏰ Tell Current Time
- 📅 Tell Current Date
- 🔍 Search on Google
- ❌ Exit Command

---

## 🛠️ Technologies Used
- Python
- SpeechRecognition
- pyttsx3
- PyAudio
